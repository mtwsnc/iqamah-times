Internal Plan · April 2026

Iqamah Times —
Automated System

No more manual entry. The website updates itself every week, automatically.

Internal Document

Right now, iqamah times are entered manually each week — which takes time and risks mistakes. This plan describes a fully automated system: when the weekly email arrives with the prayer schedule PDF, the website updates automatically, with no one needing to do anything. The system costs nothing extra per month on top of what we already pay.

Step One

Mailing List — Google Groups

Since we already have Google Workspace for Nonprofits, we can set up the mailing list at no extra cost using Google Groups — one address, one authorized sender, everyone else just receives.

One shared group address

A Google Group is created (e.g. iqamah-times@mtws.org). The secretary sends one email to this address and it delivers to every subscriber automatically.

Announcement-only — no replies, no outside senders

Only the secretary's email can send to the group. Subscribers receive the email but cannot reply to it, and no one outside can send to it. This prevents accidental reply-alls and spam.

System email is also a subscriber

Our automation address is added as a subscriber. When the secretary sends the weekly PDF, both the congregation and our system receive it simultaneously — no extra steps needed.

Managing subscribers

Adding or removing people is done through the Google Groups admin panel — no technical knowledge required. New members can also be allowed to subscribe via a link.

Google Groups is included with Google Workspace for Nonprofits at no additional cost. No new tools or subscriptions are needed.

How It Works

From email to website — automatically

The secretary's process doesn't change at all. Everything else happens on its own within seconds of the email being sent.

1. Weekly email arrives

The secretary sends the weekly schedule to the mailing list as usual. The email includes a PDF with the iqamah times for the coming week.

2. Cloudflare receives the email

Cloudflare already manages our website's domain. It can also receive emails. When the iqamah email arrives, Cloudflare opens it and extracts the PDF — all within seconds.

3. PDF is read and decoded

Our system reads the text inside the PDF and finds every prayer name and time — whether times vary by day, or whether it's a special Daylight Saving Time schedule.

4. Times are saved to the database

The parsed times are stored in Supabase — one entry per week. Each day gets its own set of prayer times, so any variation (like a different Maghrib on Friday) is stored precisely.

5. Website shows the correct times

The iqamah website automatically reads from the database and always displays today's correct times. No login required, no manual entry needed.

Built-In Reliability

What the system handles automatically

Every edge case we've seen in the weekly PDFs is accounted for.

Split Maghrib times

When Maghrib is different on Monday–Thursday vs. Friday–Sunday, the system handles it correctly for each individual day.

Daylight Saving Time weeks

Some weeks the PDF has two full columns. The system detects this and saves the correct time for each day without any manual intervention.

Late or duplicate emails

If the email arrives late, the previous week's times remain visible. Duplicate emails are safely ignored — no double updates.

Unreadable PDFs

If a PDF can't be parsed, the system logs it for review and keeps the previous times displayed — the website never goes blank.

Implementation

What needs to be done

Once approved, here is the complete list of steps to go live.

  • Create the Google Group (iqamah-times@mtws.org) with announcement-only settings
  • Add the secretary's email as the sole authorized sender; add congregation members as subscribers
  • Add the system email address as a subscriber so it receives the weekly PDF alongside members
  • Set up the iqamah times table in our existing Supabase database
  • Configure Cloudflare email routing to listen on the correct address
  • Build the PDF-reading logic on Vercel — turns the PDF into structured data
  • Update the website to read times from the database instead of a static list
  • Test with all known PDF formats: regular, split Maghrib, and Daylight Saving Time
